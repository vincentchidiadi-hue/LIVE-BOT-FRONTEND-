Live Authorization

Reported by backend /api/healthAwaiting report
Frontend can arm live tradingNo — arming is server-side only

Live execution is armed by LIVE_TRADING_ENABLED=true, a matching LIVE_TRADING_ACK, and a configured wallet key on the server. Once the server is armed it starts operating automatically on boot and after restarts — this dashboard never needs to arm it and never can. While unarmed it keeps re-checking readiness and resumes automatically the moment the backend reports every check passing.
